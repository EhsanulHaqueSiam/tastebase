# tastebase

A curated UI component library and inspiration archive, plus an agent tool (CLI, MCP server, agent skill) so coding agents pick good UI instead of defaults.

- **Registry**: hand-picked components, libraries and reference sites as typed files, each with a note on why it is good.
- **Site**: a premium browser for the registry, with live previews, ⌘K search and trending.
- **Agent**: `npx tastebase` (search, trending, add, inspo) and `npx tastebase mcp`, all reading the same registry.
- **Trending**: a daily GitHub Action records GitHub star deltas and npm downloads.

Status: design phase. Home page directions are in [`docs/mocks/home.html`](docs/mocks/home.html).
